# Trình xem kết quả xổ số tổng hợp bằng PHP

**Code php web xem kết quả xổ số các giải sau:**

* Xổ số kiến thiết miền bắc
* Xổ số Vietlott 6/45 và 6/55
* Vietlott 3d, 3d pro và keno


Upload toàn bộ file lên hosting, chạy cron file cron.php trong thư mục data để cập nhật cơ sở dữ liệu mới nhất.
